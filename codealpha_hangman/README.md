# 🎮 CodeAlpha Hangman Game

## 📌 Description

A console-based Hangman Game developed in Python as part of the **CodeAlpha Python Programming Internship**.

The game randomly selects a word from a selected category, and the player has to guess the word one letter at a time before running out of allowed wrong guesses.

## ✨ Features

- 🎯 Random word selection
- 📚 Multiple word categories
- 🐯 Animals category
- ⚽ Sports category
- 💻 Programming category
- 🔤 Letter-by-letter guessing
- ❤️ Maximum 6 wrong guesses
- 📝 Displays guessed letters
- 🔍 Shows the progress of the hidden word
- ⚠️ Input validation
- 🔄 Detects repeated guesses
- 🏆 Win and lose conditions

## 🛠️ Technologies Used

- Python 3
- `random` module
- Lists
- Dictionaries
- `if-elif-else`
- `while` loop
- `for` loop
- String methods
- User input

## 🎮 How to Play

1. Run the Python program.
2. Select a category.
3. The game randomly selects a word.
4. Guess one letter at a time.
5. Correct guesses reveal the letters.
6. Incorrect guesses increase the wrong-guess count.
7. Guess the complete word before reaching 6 wrong guesses.

Make sure Python 3 is installed.

Open the terminal in the project folder and run:
