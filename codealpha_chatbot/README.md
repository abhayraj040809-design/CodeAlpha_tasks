# 🤖 Rule-Based Chatbot

A simple and interactive **Rule-Based Chatbot** built using Python and CustomTkinter.

The chatbot provides a graphical user interface where users can communicate with the bot and receive responses based on predefined rules. It can handle greetings, basic questions, jokes, date/time queries, help commands, and exit commands.

## 📌 Project Overview

This project demonstrates how a basic chatbot can be created using **rule-based logic** without Artificial Intelligence or Large Language Models.

The chatbot analyses the user's message and checks it against predefined conditions using Python's `if`, `elif`, and `else` statements.
